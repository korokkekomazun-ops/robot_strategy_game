# Unity内でのバランス調整

1. 再生を停止し、Tools > Robot Strategy > Balance Settingsを開く。
2. 「共通Prefabを選択」を押す。
3. 各タブの折りたたみを開いて編集し、「変更を保存」を押す。

機体：戦車・戦闘機・船・トランスフォーマー・人型・巨大機体のstatsと初期適性。
敵・拠点：中央ボス、小型モンスター、拠点のstats。
相性・適性：C/B/Aの移動速度倍率、機体同士の攻撃倍率。
強化・倍率：巨大機体のHP・攻撃・装甲倍率、独立した速度倍率、CP倍率、開発の1段階ごとの増分。

## statsの意味
Max HP＝最大HP、Attack＝攻撃、Armour＝装甲、Damage Taken Multiplier＝被ダメージ倍率、Move Speed＝地形補正前の速度、Attack Range＝射程、Attack Interval＝攻撃間隔（秒）。
地形のground/sea/skyは陸/海/空の初期適性です。開発で上げた段階数を加え、Aで上限になります。
巨大機体はHP・攻撃・装甲を5倍、速度は1倍にしました。基礎速度3、速度強化0なら地形補正前の速度は3です。

## 攻撃相性
配列に攻撃側attacker・防御側defender・倍率attackMultiplierを追加します。
未登録は1倍。同じ組み合わせを複数登録した場合は先頭を使用。怪獣と拠点は対象外です。
国の攻撃補正 → 機体の攻撃相性 → 防御側の装甲 → 防御側の被ダメージ倍率の順で計算します。

## 再生中に試す
戦闘開始後「現在のシーンを選択」を押して調整し、「生存中の機体・敵へ反映」を押します。
HP割合を保って能力を更新し、大破済みの機体は復活しません。選択中の初期設計の能力プレビューも新設定に基づきます。
再生中の変更は再生終了で戻ります。採用する値は停止後に共通Prefabへ設定して保存してください。
怪獣は従来どおり中央に固定されています。Move Speedを上げても移動は開始しません。
