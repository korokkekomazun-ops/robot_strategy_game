# 機体の基礎能力と砂地

初期機体のポイントは基礎能力に加算します。基礎能力と初期適性そのものはポイントを消費しません。
HP・攻撃・装甲・速度の強化量とポイント費用は従来の設定を使用します。
初期適性に追加強化を加え、Aが上限です。Aの項目は追加購入できません。

|種類|基礎HP|攻撃|装甲|基礎速度|射程|攻撃間隔|森・陸|海|空|砂|
|---|---:|---:|---:|---:|---:|---:|---|---|---|---|
|戦車|180|16|6|2|3|1.4|B|C|C|A|
|戦闘機|80|14|1|5|3|0.9|C|C|A|C|
|船|220|20|8|2|4|1.8|C|A|C|C|
|トランスフォーマー|120|12|3|3.5|2.5|1|B|C|B|B|
|人型|100|10|2|3|2.5|1|A|C|C|B|
|巨大機体（倍率前）|140|14|4|2|3|1.5|B|C|C|C|

巨大機体はHP・攻撃・装甲に既存の5倍倍率を掛け、初期値は700/70/20です。速度には掛けません。
適性C/B/Aの速度倍率は0.5/1/1.5。戦闘機は地面にかかわらず空適性を使用します。

## 砂地
既存のsand water3素材を使い、中央を通る十字形の砂地（初期幅8マス）を追加しました。
森・陸と別の地形判定です。境界を通過すると移動速度が切り替わります。
開発画面の左隣に砂地適性の強化欄があります。初期ポイント、戦闘中CP、改造、設計図獲得に対応しています。
NPCも種類別の基礎能力と初期適性を使用します。

## 編集
Tools > Robot Strategy > Balance Settings → 共通Prefabを選択。
機体タブでstatsとground/sea/sky/sand、相性・適性タブで速度倍率・砂地の道幅・素材を調整します。
砂地の道幅は再生開始時に適用されます。能力と適性は再生中の反映ボタンで試せます。
船の陸上移動禁止やトランスフォーマーの変形は今回追加していません。

コンパイルと、ポイント/CP・旧設計データ互換・設計図獲得・地形別速度の自動テストは確認済み。
