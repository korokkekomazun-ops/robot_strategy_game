# LAN対戦（4人）

## 起動方法

1. Unityの再生を止め、スクリプトの読み込みが終わるまで待ちます。
2. `Assets/Scenes/Title.unity`を開いて再生し、「LAN対戦（4人）」を押します。`robotdevelop`を直接再生する場合は、マップ選択画面の左上に同名のボタンがあります。
3. 1台で「ホストとして作成」を押します。ほか3台はホストのIPv4アドレスを入力して「IPへ参加」を押します。
4. ホストが森林・砂地／砂地のみ／砂地と川からマップを選択します。その後、各プレイヤーがA～Dの国家 → 機体種類 → 初期ポイント配分を選び、確定します。
5. 4人が確定すると、3・2・1 → 戦闘スタートとなります。3人以下では開始せず待機します。LAN対戦にNPCは入りません。

接続画面とホストの準備完了画面に、そのPCのIPv4候補を表示します。複数出た場合は、ほかのPCと同じWi-Fi／LANにつながるアドレスを使ってください。初期入力の`127.0.0.1`は同じPCで複数起動する確認用です。別PCからはホストのLANアドレスを入力します。

## 4台へ渡すビルド

UnityのFile → Build ProfilesでWindows用にBuildし、出力先の実行ファイルとデータフォルダーなどを含む**出力フォルダー全体**を4台へコピーしてください。全員が同じビルドを使います。Title、MainScene、robotdevelopを有効なScene Listに含めます。共通Scene Listへrobotdevelopを追加してあります。独自のBuild ProfileでScene Listを上書きしている場合は、そのリストにも追加してください。

1台をUnity Editor、残り3台を同じ内容のビルドにしても確認できます。Unity Editorで再生を一時停止するとホストの進行・同期も停止するため、対戦中はPauseしないでください。

Windowsから通信の許可が出た場合は、使用するプライベートネットワークでゲームを許可してください。通信はUDP 7777です。接続できないときは、同じLANか、ホストIPが正しいか、ゲストWi-Fiの端末間通信制限がないかを確認してください。

## 国家・配置・色

国家は各プレイヤーが自由に選択でき、同じ国家が複数いても対戦できます。
国家を初めて選択する指示を**ホストが受け取った順**に、次の席を確保します。

| 選択順 | 表示 | 配置 | 初期色 |
| --- | --- | --- | --- |
| 1 | P1 | 右上 | 青 |
| 2 | P2 | 左上 | 赤 |
| 3 | P3 | 左下 | 緑 |
| 4 | P4 | 右下 | 黄 |

ホストが必ずP1になるわけではありません。確定前に国家を選び直しても席は変わりません。準備中に退出した人の席は、新しく国家を選んだ人が使用できます。機体名・拠点名・自分のCP欄にP番号を表示し、機体・HPバー・足元の印もプレイヤー色になります。

色は共通Prefabの`Nation A/B/C/D Color`で調整します。LANではこの4色をP1/P2/P3/P4の色として使います。国家ボーナスは選んだ国家のものが適用されます。D国の「他国への倍率」は、別プレイヤーでも同じD国なら適用しません。

## 戦闘操作と判定

- 自分の機体を左クリック、続いて地面を左クリックすると移動します。右クリックでも移動指示を出せます。
- WASD／矢印キー・マウス中ドラッグでカメラ移動、ホイールで拡大縮小します。
- 開発・改良・配備の支払いと、小型モンスター撃破のCPはプレイヤーごとに管理します。
- 相手の機体を大破させると、撃破したプレイヤーの一覧へ設計図を追加します。同じ国家同士でも獲得でき、すでに持っている同じ設計図は重複しません。改良は元を残して新設計を追加します。
- 移動、戦闘、HP、CP、配備、設計図獲得はホストが判定します。他人の機体への移動指示や、所持していない設計の配備は受け付けません。
- 中央ボスへ最後の一撃を与えたプレイヤーのP番号・国家をリザルトに表示します。
- 対戦開始後の途中参加、切断後の対戦復帰、ホストの引き継ぎには対応していません。参加者の切断時は対戦中止となり、タイトルへ戻って作成し直します。

## 編集する場所

既存の機体ステータス、地形適性、攻撃相性、CP費用、巨大機体の速度設定は、`Assets/_Project/Prefabs/System/BattleManager.prefab`とTools → Robot Strategy → Balance Settingsで編集します。LANの生存中ユニットへの設定反映はホスト側から行います。

追加したLAN画面を再生前にHierarchyから調整するには、robotdevelopを開き、Tools → Robot Strategy → Create Editable Battle UIを実行してください。Battle UI内の「LAN接続」「LAN参加待ち」を編集できます。既存のボタン・パネル配置は維持します。

### 通信処理のファイル

- `Assets/_Project/Scripts/Network/LanConnect.cs`：部屋作成、IP接続、満員・途中参加の拒否、接続エラー。
- `Assets/_Project/Scripts/Network/PlayerSeats.cs`：国家選択順の席確保、四隅、所有者判定。
- `Assets/_Project/Scripts/Network/NetworkData.cs`：送受信するデータの形式。
- `Assets/_Project/Scripts/Network/OnlineBattle.cs`：参加状況、準備完了、ホストの操作判定、状態同期。

## 検証範囲

Unity 6000.4.8f1とプロジェクト内パッケージのDLLを参照してコンパイルを確認しました。席順、再選択、退出した席の再利用、所有者制限、同国家間の設計図獲得、CP分離、配備支払い、改良による新設計追加は自動テストで確認しています。

4台の実機接続、Unityでの画面操作、ビルド出力の動作は未検証です。初回は、4人で同じ国家を選択 → 配置と色を確認 → 各自の機体を移動 → 配備で本人だけ600CP減ることを確認 → ボス撃破時に全員のリザルトが一致することを確認してください。
