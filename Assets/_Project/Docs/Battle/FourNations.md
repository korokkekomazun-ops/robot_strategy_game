# 4陣営の試作

robotdevelopから再生し、国家・機体・能力を決めて出撃します。
A国：左下・青、B国：右下・赤、C国：左上・緑、D国：右上・黄。
各国1拠点とInitial Robot Count分の機体をマップ内に配置します。
選んだ国家が手動操作対象で、それ以外の3国はNPCです。NPCは近い敵へ移動して射程内で攻撃します。
NPCの初期設計は確認用の固定値です。4人の通信対戦・NPCによる開発や追加生産はまだ実装していません。

## Inspector
共通PrefabのBattleManagerでFour nations / corner deploymentを開きます。
Corner Inset：四隅から内側へ離す距離。
Nation A/B/C/D Color：機体、HPバー、足元マークの国別色。
Npc Auto Move：NPCの自動移動。無効でも射程内の相手には攻撃します。

## 設計図
HPを0にした最後の攻撃者が敵機の設計図を獲得します。機体の所有国が獲得先です。
怪獣・拠点には機体設計図はありません。元の国の設計図は削除しません。
獲得は無料、配備には従来どおりCPが必要です。自国が獲得すると「配備」一覧に「鹵獲：…」が追加されます。
同じ設計図は重複せず、改良された別の設計図は別枠です。獲得した設計の能力は維持し、配備先の所属・色は自国になります。
C国の巨大機体も鹵獲できます。巨大機体のCP倍率は維持します。
NPCが味方機を大破させた場合も、そのNPC国の設計一覧に記録します（NPCは自動生産しません）。

コンパイルと設計図の獲得ロジックの自動テストは確認済み。Unity上の配置・NPC戦闘は未確認です。
