# マップ選択と小型敵の集団出現

## 遊ぶ手順

Titleから「ひとりで確認」、またはrobotdevelopを直接再生します。最初のマップ選択で以下を選べます。

- 森林・砂地：これまでの森と、中央を十字に通る砂地。
- 砂地のみ：50×50マスすべて砂地。
- 砂地と川：50×50マスの砂地に、幅3マスの曲がった川。中央ボスと四隅の拠点は砂地に配置します。

続いて国家・機体・初期ステータスを選び、戦闘を開始します。

LAN対戦ではホストがマップを選択し、全員がそのマップで対戦します。参加者はホストの選択後に国家選択へ進みます。国家の重複選択と、選択順の四隅配置は従来どおりです。今回の更新を含む同じビルドを4台へ配布してください。旧版との接続は受け付けません。

## 小型敵の増援

戦闘開始から10秒後に最初の増援、その後も10秒ごとに10～20体をランダムな数でまとめて生成します。戦闘準備中やカウントダウン中には生成しません。

中央ボスから約3マス離れた場所から配置を始め、空きがない場合は少し外側へ広げます。同じ場所に重ならないようにし、各個体は最も近い拠点へ向かいます。小型敵の同時生存上限は120体です。上限までの残り枠や空き場所が少ない場合は、その数だけ出現します。

## Unityで調整する場所

Tools → Robot Strategy → Balance Settings →「共通Prefabを選択」で設定できます。

「敵・拠点」タブ：

| 項目 | 初期設定 |
| --- | --- |
| 増援の間隔（秒） / Spawn Interval | 10 |
| 1回の出現数・最小 / Min Enemies Per Wave | 10 |
| 1回の出現数・最大 / Max Enemies Per Wave | 20 |
| 小型敵の同時生存上限 / Max Small Enemies | 120 |
| ボスからの出現距離 / Spawn Radius | 3 |

「相性・適性」タブ：

- 編集プレビューのマップ / Battle Map：停止中のMainSceneで表示するマップ。
- 川幅（マス） / River Width：1～5マス、初期値3。
- 川の素材 / River Sprite：任意のSprite。空欄の初期状態では青い水面を表示。
- 森林・砂地マップの砂地の道幅、各地形の適性倍率もここから調整できます。

停止中のプレビューを更新するときは、Tools → Robot Strategy → Preview Battle in MainSceneを実行します。マップの選択ボタンを再生前にHierarchyで編集したい場合は、robotdevelopでTools → Robot Strategy → Create Editable Battle UIを実行してください。

砂地では各機体のSand適性、川ではSea適性を使用します。戦闘機などの飛行ユニットはどちらでもSky適性を使用します。川は移動速度が変わる地形で、通行禁止にはしていません。

設定は`Assets/_Project/Prefabs/System/BattleManager.prefab`のInspectorでも変更できます。停止中に変更して保存すると、次回の戦闘に反映されます。

## 実装と確認範囲

`BattleManager.cs`が増援、`EnemyGroup.cs`が配置候補と上限、`MapPattern.cs`が地形配置、`BattleMaps.cs`がマップ選択とタイル反映を担当します。オフラインのシーン移動はBattleSession、LANの地形共有はForestLanBattleとLanBattleProtocolを通します。

Unity用アセンブリでのコンパイルと、地形配置・川の接続・拠点位置・20体分の配置間隔・上限・シーン間のマップ受け渡し・地形適性の自動テストを確認しました。Unityでの実際の描画と、4台のLAN接続は未検証です。
